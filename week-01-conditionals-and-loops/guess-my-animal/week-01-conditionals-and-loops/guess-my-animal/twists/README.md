# 🧩 Guess My Animal — Twists

These are additional challenges for the original Guess My Animal assignment from Code in Place X.

Each twist adds a new feature, introduces a bug to debug, or changes the game's behavior.

## Twist Challenges

| # | Twist | Main concept |
|---|---|---|
| 01 | Hello, Detective | User input and string formatting |
| 02 | Backwards Day | Debugging conditional logic |
| 03 | Victory Lap | AI prompting and emoji output |
| 04 | Endless Party | Debugging loops and conditions |
| 05 | Special Guest | String comparison and case handling |
| 06 | Crash Landing | Debugging variable initialization |
| 07 | Clue Please! | Conditional branching and hints |
| 08 | Easy Mode | User preferences and prompt engineering |
