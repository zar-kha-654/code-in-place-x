# 🐾 Guess My Animal

**Week:** 01 — If Statements and While Loops

## 📌 Problem Overview

Guess My Animal is an interactive guessing game where the computer secretly selects a random animal, and the player tries to identify it by asking yes-or-no questions.

The program uses an AI model to answer questions about the selected animal.

## 🎯 Learning Objectives

- Work with functions.
- Use random selection.
- Handle user input.
- Implement loops and conditional logic.
- Integrate an AI model using `call_gpt()`.
- Practice prompt engineering.

## 📝 Assignment Requirements

1. Select a random animal using `get_random_animal()`.
2. Allow the user to ask yes-or-no questions.
3. Use `call_gpt()` to determine the answer.
4. Continue the game until the user guesses the correct animal.

## ⚙️ Provided Functions

| Function | Purpose |
|---|---|
| `get_random_animal()` | Selects a random animal. |
| `call_gpt()` | Sends a prompt to an AI model and returns its response. |

## 📂 Files

- `main.py` — Original assignment implementation.
- `twists/` — Additional problem variations and their solutions.

## 💡 Problem-Solving Notes

The game combines a guessing loop with AI-generated answers. The program needs to distinguish between a yes-or-no question and the player's final guess.
