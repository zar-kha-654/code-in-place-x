
# Khansole Academy

**Week 02 — Numbers and Random**

Khansole Academy is a Python programming assignment from Stanford Code in Place. The program generates random addition questions and challenges the user to answer **three questions correctly in a row**.

## Original Assignment

- **Topic:** Random Numbers, Arithmetic, While Loops, and User Input
- **Language:** Python
- **Goal:** Practice arithmetic operations, random number generation, loops, and conditional statements.

## What I Practiced

- Generating random numbers using `randint()`
- Performing arithmetic operations
- Taking user input
- Using `while` loops
- Applying `if-else` conditions
- Tracking consecutive correct answers
- Building small interactive Python programs
