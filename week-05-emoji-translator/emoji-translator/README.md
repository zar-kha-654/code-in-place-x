# 💗 Week 06 — Chatbot

> Stanford Code in Place X | Fall 2026

## 📌 About This Project

Chatbot is a Python assignment from Week 6 of Code in Place X.

The project explores how to build an interactive AI chatbot using Python and the `call_gpt` function.

The chatbot starts with a simple conversation and gradually gains the ability to remember messages, maintain a personality, and manage its conversation history.

## 🎯 Main Assignment

The assignment contains eight milestones:

1. **Goldfish Bot** — Build a basic chat loop.
2. **Keep a Record** — Store conversations using a list of dictionaries.
3. **Peek at the Record** — Display the saved conversation history.
4. **Give It a Memory** — Send the entire conversation to GPT.
5. **Give It a Personality** — Use a system message to define the chatbot's behavior.
6. **Rewind** — Remove the last conversation exchange. *(Optional)*
7. **Memory Budget** — Manage conversation length using a word limit. *(Optional)*
8. **Compact** — Summarize older messages instead of simply forgetting them. *(Optional)*
